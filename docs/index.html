Flutter ו-Dart — לומדים בעברית, גם ללא אינטרנט

ברוכים הבאים לערכת הלימוד. Flutter יוצר ממשקים ליישומים, ו-Dart היא שפת התכנות שבה משתמשים.

1. בדיקת התקנה

פתחו PowerShell חדש ובצעו:

flutter --version
dart --version
flutter doctor -v

2. שיעור Dart ראשון

void main() {
  String name = 'עולם';
  print('שלום $name');
}

שמרו בקובץ hello.dart והריצו dart run hello.dart.

3. Flutter ראשון

בתיקייה samples/hello_flutter יש פרויקט לדוגמה. היכנסו אליה והפעילו:

flutter pub get --offline
flutter run -d windows

כדי לבנות אפליקציית Windows יש להתקין בנפרד את כלי C++ של Visual Studio.

4. Android

חברו מכשיר עם אפשרויות מפתחים וניפוי USB המופעלות בהסכמה. בדקו flutter devices, והשתמשו ב-flutter run. פרויקטים חדשים עשויים להזדקק לגרסאות Gradle וחבילות שלא נארזו.

5. מצב ללא רשת

השתמשו ב-flutter pub get --offline עבור חבילות שכבר נמצאות במטמון. לפעמים נדרש להוסיף מראש מטמונים לפי הפרויקט לפני ניתוק מהרשת.

6. מידע נוסף

במאגר מתפרסמות גרסאות הערכה. המדריך הזה מקומי ופועל ללא חיבור לרשת.
